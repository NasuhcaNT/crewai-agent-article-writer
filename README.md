# CrewAI Agent Article Writer

A beginner-friendly multi-agent content generation project built with **CrewAI**, **Gemini**, and **Serper**.

This project demonstrates how to create a small AI team where each agent has a specific role:

- **Researcher Agent** → collects up-to-date information from the web
- **Writer Agent** → turns research into a readable Medium article
- **Editor Agent** → reviews the article for clarity, consistency, and quality

## Features

- Multi-agent workflow with CrewAI
- Sequential task execution
- Web research with SerperDevTool
- Content generation with Gemini
- Beginner-friendly project structure
